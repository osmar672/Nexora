# Branding de Nexora

Coloca aquí recursos gráficos originales del proyecto, por ejemplo:

- `logo.svg`: logo vectorial principal.
- `wallpaper.png`: fondo de escritorio.
- `icon.png`: icono de aplicaciones.

Para integrarlos en Archiso, copia los archivos necesarios a `profile/airootfs/usr/share/...` y mantén una licencia clara para los recursos gráficos. Evita usar marcas de Arch Linux o KDE de forma que sugieran que son proyectos oficiales.
